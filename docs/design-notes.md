# 设计笔记：音高模型

这份笔记记录音高相关的几个设计决定，以及背后的取舍——主要写给未来的自己。

## 为什么用 YIN 而不是自相关峰值

最朴素的基频估计是找自相关的最高非零延迟峰，但它有两个老毛病：

1. **倍频程误判**：谐波丰富的信号里，2×周期处的峰可能比真周期还高。
2. **共振峰干扰**：声道共振会在自相关里造出假峰。

YIN 用**差分函数** `d(τ) = Σ(x[j] - x[j+τ])²` 取代自相关，再做**累积均值归一化**
（CMNDF）把 `d'(0)=1`、并压低小 τ 处的取值，最后用**绝对阈值**挑第一个足够深的谷。
「第一个」而非「最深」是关键——它天然偏向真周期，抑制倍频程误判。

实现上差分函数用 FFT 自相关加速：

```
d(τ) = r(0) + (窗口能量) − 2·acf(τ)
```

## 清 / 浊判定：宁可漏判也别误判

CMNDF 找不到过阈值的谷时怎么办？早期版本无条件退回全局最小，只要 `< 1` 就算浊音——
结果**白噪声几乎全被判成浊音**（噪声的 CMNDF 最小值经常偶然落到 0.8 左右）。

修正：只有当全局最小明显偏低（`< min(0.3, 1.5×阈值)`）时才勉强接受为浊音，否则判清音。
歌声合成里，把清音误判成浊音会在气声段冒出可闻的假音高，比漏判难听得多。

## 从音符到基频轨迹：三层表情

静态音高只是骨架。让合成「像人唱」的是叠加在上面的三种表情，都在**对数频率域**操作
（因为音乐感知是对数的）：

| 表情 | 建模 | 参数 |
|------|------|------|
| 滑音 portamento | 音高突变处用余弦 S 形过渡 | 过渡时长（ms） |
| 起音过冲 overshoot | 段首半周期先冲高再回落 | 峰值（音分）、起音时长 |
| 颤音 vibrato | 正弦音高调制，带渐入包络 | 速率（Hz）、深度（音分） |

颤音的**渐入**很重要：真人是先稳住音高、再慢慢加颤音，一上来就满深度会显得机械。

## 单位：为什么坚持用音分

音分（1 音分 = 1/1200 八度）是**感知均匀**的音高单位：不管在低音区还是高音区，
50 音分听起来都是「半个半音」。所以容差（比如「音准误差 < 50 音分」）、颤音深度、
过冲幅度全用音分表达，而不是 Hz——Hz 在不同音区代表的感知距离天差地别。

## 已知局限

- `F0_CEIL = 1000 Hz` 对花腔女高音偏低（见 `constants.py` 里的 TODO）。
- YIN 是逐帧独立的，没有跨帧平滑 / 维特比路径，快速滑音处偶有跳变。
- 抛物线插值假设谷附近是抛物线，深谷够用，浅谷时精度有限。
